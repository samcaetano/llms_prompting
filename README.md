# LLMs & prompting
Repo for my studies on LLMs and prompting

This consists of samples of using open-access LLMs and building samples of interactions with them. I also want to add prompting use cases.


## Experiments on local LLMs

To do so, I am using (as a starter) Llama-2, implemented as C++ code, known as Llama-CPP, which is a reimplementation of the original Meta Llama-2 model, but in a more flexible and lightweight format, so we can run LLM on ordinary machines (such as my laptop) which are often not so computationally powerful

- Llama-CPP:https://github.com/ggerganov/llama.cpp

- Complete Llama-CPP guide: https://llama-cpp-python.readthedocs.io/en/latest/#chat-completion
